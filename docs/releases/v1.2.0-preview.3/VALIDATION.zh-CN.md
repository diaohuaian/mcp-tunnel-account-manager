## 环境适配与注意事项

- 使用工作区内显式 TEMP/TMP，避免默认临时目录受当前运行环境限制；未修改系统权限、ACL 或全局策略。
- 建议目标机解压到短、固定、可写的目录，例如 C:\MCP 或 D:\MCP。
- 本机测试使用捆绑 Node v25.9.0（非 LTS）和 Windows PowerShell 5.1；未验证全部最低或替代运行时版本。
- 包含在 `v1.2.0-preview.3` 中的修改确保了在前端操作切账号时，掩码绝对不会覆盖持久化凭据。
