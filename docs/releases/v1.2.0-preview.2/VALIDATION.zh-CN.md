## 环境适配与注意事项

- 使用工作区内显式 TEMP/TMP，避免默认临时目录受当前运行环境限制；未修改系统权限、ACL 或全局策略。
- 当前宿主有大小写重复的代理环境变量，测试子进程规范化了变量名；后台启动测试使用文件输出，避免后台进程持有测试捕获管道。这些是测试驱动适配，不是对发行程序的改写。
- 完整包最长 ZIP 条目路径为 161 字符。深目录解压实测触及 Windows 传统路径限制；改用短的中文/空格测试目录后成功。建议目标机解压到短、固定、可写的目录，例如 C:\MCP 或 D:\MCP。
- 本机测试使用捆绑 Node v25.9.0（非 LTS）、Python 3.14.4 和 Windows PowerShell 5.1；未验证全部最低或替代运行时版本。
- 上述文件准备与验证阶段没有覆盖三个 ZIP，也没有改动原项目、真实账号库、桌面快捷方式或 GitHub 远端。后续经维护者授权的源码同步和 Release 发布是独立步骤，不属于这里的隔离验证。

## 部署前仍须准备

Overleaf 的 Git 业务需自行安装 Git 并加入 PATH，配置有 Git integration 权限的项目和自己的 token；只有本地编译另需 latexmk/TeX。Antigravity 需 Python 及已登录 IDE。可选 DSH 需相容宿主和依赖。所有外部业务需要用户自己的授权、凭据和网络，这不是全离线系统镜像。
